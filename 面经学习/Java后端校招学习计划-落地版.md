## 今天安排：5、6、7 复习

### 第 1 轮：目录扫描

目标：知道每门课的主线，不追求细节全背。

- 计网：从一次 HTTP 请求出发，串起 DNS、TCP、TLS、HTTP、Cookie/Session/Token、安全。
- 操作系统：从一次请求在服务器中的执行出发，串起进程线程、用户态/内核态、上下文切换、IO 多路复用。
- Java 并发：从多线程共享数据出发，串起 JMM、锁、CAS、AQS、线程池、ThreadLocal、并发容器。

### 第 2 轮：核心主线复习

目标：每个主题能讲出“为什么有这个问题”和“怎么解决”。

- 每个主题先用 3-5 句话讲清楚。
- 再补 3-5 个高频问题。
- 最后准备 1 个项目关联说法。

### 第 3 轮：口述自测

每个主题按下面格式自测：

```text
这个知识点解决什么问题？
核心机制是什么？
面试官最可能怎么问？
我的标准回答是什么？
还能怎么追问？
项目里怎么联系？
```

## 一周安排：JVM + Spring

### Day 1：JVM 内存结构与对象创建

- 运行时数据区：程序计数器、虚拟机栈、本地方法栈、堆、方法区/元空间。
- 对象创建流程：类加载检查、内存分配、初始化零值、设置对象头、执行构造方法。
- 对象内存布局：对象头、实例数据、对齐填充。

### Day 2：类加载机制

- 类加载阶段：加载、验证、准备、解析、初始化。
- 双亲委派模型。
- 类初始化触发时机。
- 常见追问：为什么需要双亲委派、能不能打破。

### Day 3：垃圾回收与 OOM

- 判断对象是否可回收：引用计数、可达性分析、GC Roots。
- 引用类型：强、软、弱、虚。
- GC 算法：标记清除、标记复制、标记整理、分代收集。
- 常见 OOM 与排查思路。

### Day 4：Spring IOC

- IOC/DI 思想。
- BeanDefinition、BeanFactory、ApplicationContext。
- Bean 生命周期。
- 循环依赖。

### Day 5：Spring AOP 与事务

- AOP 核心概念：切面、切点、通知、代理。
- JDK 动态代理与 CGLIB。
- 事务传播行为、隔离级别、失效场景。

### Day 6：Spring MVC

- DispatcherServlet 请求流程。
- HandlerMapping、HandlerAdapter、ViewResolver。
- 参数绑定、消息转换器、异常处理。

### Day 7：Spring Boot

- 自动装配。
- starter 机制。
- 启动流程。
- 常见注解。

## 微服务处理策略

校招近期不系统学习微服务，只保留以下概念：

- 注册中心：服务如何发现彼此。
- 配置中心：配置如何统一管理。
- 网关：统一入口、鉴权、路由、限流。
- 服务调用：HTTP/RPC。
- 限流熔断：防止局部故障拖垮整体。
- 分布式事务：多个服务或数据库之间的数据一致性问题。
