## 一、学习目标

学完 JVM 后，要能讲清楚三件事：

1. Java 程序是如何被加载和执行的。
2. Java 对象在内存中如何存放，垃圾回收如何判断和回收对象。
3. 出现内存问题或 GC 问题时，如何定位方向。

## 五、待自查易错方向

> 这里只列检查方向，不写答案。你写完后，我会按这些点帮你抓错，并直接把回答替换成更精确的学习版。

- 方法区是规范概念，元空间是 HotSpot 的实现
- 栈里存的是栈帧，不是对象本体
- 准备阶段是零值，初始化阶段才执行代码赋值
- 双亲委派不是强制规则，可以被特定场景打破
- 引用计数法无法很好处理循环引用
- GC Roots 不是“所有还活着的对象”
- Minor GC、Major GC、Full GC 的触发范围和成本
- JVM 调优要先定位问题，再调整参数
