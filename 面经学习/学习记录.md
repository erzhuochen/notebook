## 四天学习目标
### Day 1：并发基础 + synchronized + volatile
- 学习内容：线程基础、线程状态、JMM、原子性、可见性、有序性、volatile、synchronized、对象头、Monitor、锁升级。
- 必须掌握：
  - volatile 能保证什么，为什么不能保证 i++ 的原子性。
  - synchronized 锁的是什么，为什么可重入。
  - synchronized 和 volatile 的区别。
  - wait、sleep、join、yield 的区别。
  - synchronized 锁升级过程。

### Day 2：线程池 + JUC + AQS + 并发容器
- 学习内容：线程池参数、线程池执行流程、拒绝策略、ThreadLocal、CAS、Atomic、ReentrantLock、AQS、CountDownLatch、Semaphore、CyclicBarrier、ConcurrentHashMap、BlockingQueue。
- 必须掌握：
  - 线程池七大参数和任务执行流程。
  - 为什么不推荐 Executors。
  - 线程池参数如何设置。
  - ThreadLocal 为什么可能内存泄漏。
  - CAS 的问题和 ABA 问题。
  - AQS 的基本思想。
  - ConcurrentHashMap 如何保证线程安全。

### Day 3：JVM 内存结构 + 对象 + 类加载
- 学习内容：运行时数据区、程序计数器、虚拟机栈、本地方法栈、堆、方法区/元空间、运行时常量池、直接内存、对象创建过程、对象内存布局、对象访问定位、类加载过程、双亲委派模型、类初始化时机。
- 必须掌握：
  - JVM 运行时数据区有哪些。
  - 堆和栈分别存什么。
  - 方法区和元空间的关系。
  - 对象创建过程和对象头内容。
  - 类加载过程。
  - 双亲委派模型是什么，为什么需要它。
  - 类什么时候会初始化。

### Day 4：GC + 垃圾回收器 + JVM 调优/OOM
- 学习内容：对象存活判断、可达性分析、GC Roots、引用类型、垃圾回收算法、分代收集、Minor GC、Major GC、Full GC、常见垃圾回收器、G1、JVM 参数、OOM、Full GC 排查、CPU 飙高排查。
- 必须掌握：
  - JVM 如何判断对象是否死亡。
  - GC Roots 有哪些。
  - 垃圾回收算法及其优缺点。
  - Minor GC、Major GC、Full GC 的区别。
  - CMS 和 G1 的区别。
  - 常见 OOM 类型和排查思路。
  - 频繁 Full GC 和 CPU 飙高如何定位。
