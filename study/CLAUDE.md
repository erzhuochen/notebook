# Study System - 学习系统说明

## 这个目录是什么

这是用户的学习笔记目录。用户会在这里创建主题文件夹，提问后会要求你将对话内容整理到对应文件中。

## 目录结构

```
study/
├── CLAUDE.md           # 本文件
├── index.md            # 主题索引（用户维护）
└── [主题名]/           # 用户创建的主题文件夹
    ├── notes.md        # 主笔记文件（或其他命名）
    └── examples/       # 代码示例文件夹（可选）
```

## 你的工作流程

1. **回答问题**：用户提问时，正常回答
2. **等待整理指示**：用户会明确告诉你"整理到 XXX 文件"
3. **整理内容**：按用户指定的文件路径整理内容

## 整理原则

当用户要求整理内容时：

- **结构化组织**：不是直接复制对话，而是重新组织成清晰的章节
- **代码示例独立**：代码示例应该完整可运行，带注释说明
- **合并而非追加**：如果文件已有内容，将新内容合理合并，避免重复
- **保持连贯**：整理后的文档应该像一篇完整文章，不是对话记录
- **深度适中**：默认深度为"初级开发需要掌握"，除非用户指定其他深度

## 整理格式建议

### 主文档（如 notes.md）
- 使用 Markdown 标题层级（##、###）
- 核心概念 → 实现原理 → 代码示例 → 常见问题
- 每个章节：是什么、为什么、怎么用

### 代码示例文件
- 文件名描述用途：`websocket-reconnect.js`
- 文件开头注释说明示例目的
- 代码完整、可运行、有必要注释
