# Study System - 学习系统说明

## 这个目录是什么

这是用户的学习笔记目录。用户会在这里创建主题文件夹，提问后会要求你将对话内容整理到对应文件中。

## 目录结构

```
study/
├── CLAUDE.md           # 本文件
├── index.md            # 主题索引（AI 维护）
└── [主题名]/           # 用户创建的主题文件夹
    ├── notes.md        # 主笔记文件
    ├── notes.assets/   # 图片资源目录
    └── examples/       # 完整代码示例（可选）
```

## 你的工作流程

1. **回答问题**：用户提问时，正常回答
2. **等待整理指示**：用户会明确告诉你"整理到 XXX 文件"
3. **整理内容**：按用户指定的文件路径整理内容
4. **维护索引**：自动更新 index.md

## 整理原则

当用户要求整理内容时：

- **结构化组织**：不是直接复制对话，而是重新组织成清晰的章节
- **代码示例默认嵌入**：代码片段直接写在文档中，**只有用户明确说"创建示例文件"时才创建 examples/ 目录**
- **合并而非追加**：如果文件已有内容，将新内容合理合并，避免重复
- **保持连贯**：整理后的文档应该像一篇完整文章，不是对话记录
- **深度适中**：默认深度为"初级开发需要掌握"，除非用户指定其他深度
- **底层实现辅助理解**：在讲解概念时，适当说明底层是如何实现的，帮助用户建立完整的技术理解（深度保持在初级开发水平）

### 整理指令词
用户的指令有明确含义，请严格遵守：

- **"整理到 [主题]"**：创建新主题或在已有主题中追加内容
- **"更新 [主题] 的 [章节]"**：修改特定章节，保留其他内容
- **"重构 [主题] 笔记"**：重新组织整个文档结构
- **"追加到 [主题]"**：在文档末尾添加新章节

## 标准文档模板

每个主题笔记应包含以下标准章节（可根据主题特点灵活调整）：

### 基础模板
```markdown
# [主题名称]

## 概述
- 是什么
- 解决什么问题
- 适用场景

## 核心概念
- 关键术语
- 工作原理

## 基础使用
- 快速开始代码
- 常见用法

## [进阶] 深入理解
- 底层实现
- 高级特性

## [进阶] 最佳实践
- 生产环境注意事项
- 常见坑点

## 参考资源
- [[相关主题]] - 内部链接
- [外部文档](url) - 官方文档、RFC 等
```

### 灵活调整
- Java SDK 类主题可增加"安装配置"章节
- 工具/框架类主题可增加"与 XX 对比"章节
- 使用 `[进阶]` `[可选]` 标记章节深度

## 内部链接规范

### 格式
- 链接格式：`[主题名-章节名](../主题目录/notes.md)`
- 示例：`[HTTP 协议-握手过程](../http/notes.md)`
- 说明：名称包含章节信息便于阅读，但链接只到文件级别保证稳定性

### 容错策略
- 章节改名时，链接仍然有效（指向文件）
- 容忍链接名称与实际章节名的小偏差
- 如需批量更新引用，用户会明确指示

## 图片与资源管理

### 图片存储
- 每个笔记文件对应一个 assets 目录
- 命名规则：`${笔记文件名}.assets/`
- 示例：`websocket/notes.md` 对应 `websocket/notes.assets/`

### 图片命名
- 格式：`file-${时间戳}.扩展名`
- 时间戳格式：`YYYYMMDDHHmmssSSS`（17位数字）
- 示例：`file-20260903143052123.png`

### 在文档中引用
```markdown
![描述](./notes.assets/file-20260903143052123.png)
```

## index.md 维护规则

### 由 AI 自动维护
index.md 是主题索引，每次整理内容后自动更新。

### 更新时机
- 首次创建新主题：在 index.md 添加新行
- 整理内容到已有主题：更新该主题的日期和标签

### 标签规则
AI 根据内容自动判断标签，使用以下维度：
- **技术领域**：`#前端` `#后端` `#网络` `#数据库`
- **编程语言**：`#JavaScript` `#Java` `#Go` `#Python`
- **应用场景**：`#实时通信` `#性能优化` `#安全` `#并发`

### index.md 格式
```markdown
# 学习笔记索引

这里记录所有学习主题。

## 已学习的主题

| 主题 | 标签 | 更新日期 | 简述 |
|------|------|----------|------|
| [WebSocket](./websocket/) | `#前端` `#网络` `#实时通信` | 2026-09-03 | WebSocket 协议和实现原理 |

---

*本索引由 AI 自动维护*
```
